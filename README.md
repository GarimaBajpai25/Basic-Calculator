# Basic Calculator

A simple and responsive calculator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Addition
- Subtraction
- Multiplication
- Division
- Clean and Responsive UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
Basic-Calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ How to Run

1. Download or Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
